# Evidencias visuales de PichuPaper

Las capturas `01`–`07` y `09`–`13` se tomaron del sitio publicado en Netlify. `08-pago-muestra.png` se actualizó desde la versión local del formulario; ese cambio todavía no está publicado. El catálogo carga desde Neon.

| Archivo | Pantalla |
|---|---|
| `01-inicio.png` | Encabezado, navegación, banner principal y presentación. |
| `02-catalogo.png` | Productos, categorías y filtro de ofertas. |
| `03-detalle-producto.png` | Galería, variante, precio, reseñas y acción de carrito. |
| `04-inicio-sesion.png` | Formulario de acceso. |
| `05-registro.png` | Formulario de creación de cuenta. |
| `06-carrito-muestra.png` | Carrito con artículos y resumen de ejemplo. |
| `07-entrega-muestra.png` | Formulario de entrega con valores de ejemplo. |
| `08-pago-muestra.png` | Métodos de pago y campos de formato; no se procesan transacciones. |
| `09-revision-muestra.png` | Revisión previa con datos de ejemplo. |
| `10-confirmacion-muestra.png` | Estado pendiente, presentado como ejemplo visual. |
| `11-validacion-errores.png` | Errores de validación del formulario de entrega. |
| `12-inicio-movil-390.png` | Inicio a 390 px de ancho. |
| `12-catalogo-movil-390.png` | Catálogo a 390 px de ancho. |
| `13-user-flow.svg`, `13-diagrama-user-flow.png` | Diagrama de navegación hasta la confirmación. |

Las pantallas `06`–`10` usan únicamente datos de muestra mostrados en el navegador para documentar el diseño. No crean una cuenta, carrito, pago ni pedido en Neon. La confirmación de ejemplo no representa una compra real. El flujo auténtico de checkout requiere iniciar sesión.
